1. Apa itu CRUD 
singkatan dari Create, Read, Update, Delete — operasi dasar untuk mengelola data di database.

2. Opm yg dipake di laravel 
MVC (Model–View–Controller) sebagai pola pemrogramannya.

3. apa itu view
bagian tampilan/UI yang dilihat user, biasanya file Blade.php

4. apa itu model 
bagian yang mengatur data & koneksi database, termasuk query ke tabel tertentu.

5. apa itu controller
bagian yang mengatur alur/logika aplikasi, menerima request, memprosesnya, lalu mengirim data ke view/model.
