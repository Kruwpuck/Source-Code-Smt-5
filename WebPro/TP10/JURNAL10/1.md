1. Apa kepanjangan AJAX 
AJAX = Asynchronous JavaScript and XML

2. Apa itu session dalam php, dan bagaimana session bekerja 
- Session adalah mekanisme penyimpanan data sementara di server berdasarkan ID unik yang dikirim oleh browser.
- session bekerja dengan menghubungkan ID unik dari browser ke data yang disimpan di server.

3. Bagaimana AJAX bekerja sthl mengerjakan soal tadi? berikan contoh kasusu dunia nyata kapan itu diperlukan
- AJAX mengirim request ke server tanpa me-reload halaman. Browser mengirim data ke file PHP, PHP memprosesnya, lalu mengembalikan hasil ke JavaScript, dan JavaScript langsung menampilkan hasilnya di halaman.
- Contoh kasus nyata: Keranjang belanja di e-commerce:
Menambah barang ke cart → langsung bertambah di icon cart tanpa reload

 4. apa manfaat utama menggunakan session dalam aplikasi web? dalam situasi apa session digunakan?
- Menyimpan data pengguna sementara di server (misalnya data login, keranjang belanja) sehingga tetap tersedia saat pindah halaman.
- Ketika aplikasi perlu mengenali pengguna selama mereka masih memakai web, seperti saat login, shopping cart, atau form bertahap.
