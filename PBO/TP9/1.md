1. Sebutkan 2 jenis casting 
Upcasting dan Downcasting

2. Sebutkan 2 jenis objek casting 
Implisit dan Eksplisit
3. Jelaskan apa itu implisit casting 
proses casting yang terjadi secara otomatis ketika sebuah variabel referensi diisikan ke variabel referensi lain yang memiliki tipe superclass dari variabel tersebut

class A {}
class B extends A {}

B b  = new B();
A a1 = b;        // implisit upcasting (reference -> reference)
A a2 = new B();  // implisit upcasting (object -> reference)

4. Jelaskan apa itu eksplisit casting
casting yang harus dituliskan secara manual oleh programmer
- Downcasting (mengacu pada subtipe objek) pasti dilakukan secara eksplisit.
A ref = new B();
B b = (B) ref;

- Upcasting (mengacu pada superclass) juga bisa dilakukan secara eksplisit, meskipun tidak wajib karena bisa implisit.
A a3 = (A) b;       // eksplisit upcasting
A a4 = (A) new B(); // eksplisit upcasting
