1. Apa perbedaan html dan jsp
- HTML (Static): Jika menggunakan HTML statis, pembaruan tampilan atau konten harus dilakukan secara manual (mengedit file HTML langsung). Misalnya, jika ingin mengubah tanggal atau gambar, kode sumbernya harus diubah manual.
- JSP (Dynamic): JSP adalah teknologi yang memungkinkan penambahan konten dinamis ke halaman web. Dengan JSP, konten dapat berubah secara otomatis berdasarkan berbagai faktor, seperti waktu, input pengguna, riwayat interaksi, atau jenis browser.

2. Disebut apakah kode java yg di-embed pada jsp
Kode Java yang disisipkan atau di-embed di dalam halaman JSP disebut sebagai Scriptlet.

3. Sebutkan 3 teknologi front end yg anda ketahui
- HTML (HyperText Markup Language): Digunakan sebagai struktur dasar halaman web
- JavaScript: Disebutkan sebagai salah satu kategori proyek dalam Netbeans ("HTML5/JavaScript")
- JSP (Java Server Pages): Digunakan sebagai teknologi view untuk menampilkan konten dinamis dan formulir kepada pengguna
