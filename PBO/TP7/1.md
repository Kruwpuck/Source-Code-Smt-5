Apakah abstract boleh ada constructor?
A : Boleh

Sebutkan 2 perbedaan dari abstract class dan interface
A :

Abstract bisa bikin method plus implementasinya, kalo interface cuma bisa deklarasi aja ga sama implementasinya

Abstract bisa ada atribut, interface gabisa

Tuliskan persamaan dari abstract class dan interface
A : Keduanya digunakan untuk menciptakan abstraksi, yang memungkinkan programmer untuk mendefinisikan metode tanpa memberikan implementasi konkret. Ini memungkinkan kelas turunan untuk mengisi implementasi sesuai kebutuhan.

Apakah mungkin bagi sebuah kelas untuk mengimplementasikan beberapa interface sekaligus? dan jelaskan!
A : Ya, kelas dapat mengimplementasikan beberapa interface sekaligus. Caranya dengan memisahkan nama-nama interface yang diimplementasikan dengan tanda koma.

Apakah sebuah abstract class dapat mengimplementasikan sebuah interface? dan jelaskan!
A : Ya, abstract class dapat mengimplementasikan sebuah interface. Ketika abstract class mengimplementasikan interface, ia tidak wajib memberikan implementasi dari semua metode dalam interface tersebut.
