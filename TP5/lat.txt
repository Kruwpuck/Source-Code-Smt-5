1️⃣ Cara agar gambar (IMG) full di Bootstrap

Kalau kamu ingin gambar menyesuaikan lebar container atau layar, gunakan class bawaan Bootstrap img-fluid.

📘 Contoh:

<img src="gambar.jpg" class="img-fluid" alt="Responsive image">

🧩 Fungsi img-fluid: Menambahkan CSS:

max-width: 100%;
height: auto;

➡️ Artinya gambar otomatis menyesuaikan ukuran parent-nya dan tidak keluar dari layout.

Kalau kamu ingin gambar benar-benar full 100% layar (tanpa container):

<img src="gambar.jpg" class="w-100" alt="Full width image">

🧠 w-100 artinya width: 100% (lebar penuh).


---

2️⃣ Apa itu Bootstrap dan fungsinya

📘 Bootstrap adalah framework CSS (dan JS) yang digunakan untuk membuat tampilan web responsif dan cepat tanpa harus menulis semua CSS dari nol.

🔧 Fungsinya:

Mempermudah pembuatan tampilan web yang rapi dan konsisten.

Sudah punya komponen siap pakai seperti: tombol, navbar, card, form, modal, grid system, dll.

Responsif otomatis di berbagai ukuran layar (mobile, tablet, desktop).

Menghemat waktu dan memudahkan kolaborasi antar developer.



---

3️⃣ 5 Class Bootstrap yang paling umum dan fungsinya

Class	Fungsi	Contoh Penggunaan

.container	Membuat pembungkus layout dengan padding otomatis	<div class="container">...</div>
.row	Membuat baris dalam sistem grid (untuk kolom)	<div class="row">...</div>
.col	Membagi layout menjadi kolom yang responsif	<div class="col">...</div>
.btn + .btn-primary	Membuat tombol (warna bisa diubah: primary, success, danger, dll.)	<button class="btn btn-primary">Klik</button>
.text-center	Mengatur teks agar rata tengah	<p class="text-center">Halo!</p>


Tambahan populer:

.d-flex → aktifkan Flexbox

.justify-content-center → rata tengah secara horizontal

.align-items-center → rata tengah secara vertikal

.w-100 / .h-100 → ubah ukuran 100%

4️⃣ Cara memanggil / memasang Bootstrap

Ada 2 cara utama:

(A) Menggunakan CDN (paling umum & mudah)

Tidak perlu download, cukup hubungkan link dari server Bootstrap.

📘 Contoh:

<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Contoh Bootstrap</title>

  <!-- CSS Bootstrap -->
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>

  <h1 class="text-center text-primary">Halo Bootstrap!</h1>

  <!-- JS Bootstrap (opsional untuk komponen interaktif) -->
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>

(B) Menggunakan File Lokal (offline)

1. Download Bootstrap dari https://getbootstrap.com


2. Simpan file bootstrap.min.css dan bootstrap.bundle.min.js di folder proyek kamu


3. Hubungkan seperti ini:



<link rel="stylesheet" href="css/bootstrap.min.css">
<script src="js/bootstrap.bundle.min.js"></script>
